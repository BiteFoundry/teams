## What's Changed

### Binary Size, Build Diet & Parity Hardening
- **Smaller Release Binaries**: Enabled `opt-level = "s"` and `panic = "abort"` in `[profile.release]`, cutting release binary sizes by ~40% with zero feature loss.
- **HTTP / CLI / MCP Parity**: Unified `serve` `edit_message` (adding optional `find`/`replace`/`subject` support) and `get_thread` onto shared CLI helpers; eliminated fragile `unwrap()` calls and fixed all Clippy warnings (`-D warnings` clean).
- **Dependency & Packaging Diet**: Upgraded `ratatui` to `0.29`, `dirs` to `6`, and trimmed `bitefoundry-html` `resvg` features; removed unused `crossterm/event-stream`, `futures`, and `hex`, moved `tempfile` to dev-dependencies, and added optional Cargo feature gates (`html-js`, `svg-graphics`, `desktop-notify`) for lightweight headless builds.
- Externalized `assets/demo.gif` to `bitefoundry.dev` to keep repository clones lean.
