## What's Changed

### Native-Terminal Input Latency & Event Loop Fix
- Replaced `crossterm::event::EventStream` and `.now_or_never()` polling (and removed contending `crossterm::event::poll(Duration::ZERO)` calls) with a dedicated lock-free `TerminalEventReader` (OS reader thread + Tokio `mpsc::unbounded_channel`), eliminating both `noop_waker` poisoning (up to 200ms timer-tick stalls) and Windows `INTERNAL_EVENT_READER` mutex blocking on every keystroke.
- Wrapped terminal output in a 64 KiB `BufWriter<Stdout>` and moved cursor positioning inside `terminal.draw()` (with queued `BeginSynchronizedUpdate`), eliminating redundant per-keystroke Hide/Show cursor flicker and multiple stdout flushes.
- Paused and resumed the dedicated reader cleanly around external `$EDITOR` handoff and Windows `Resize` VT probing.
