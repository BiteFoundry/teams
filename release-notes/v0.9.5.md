## What's Changed

### Sync & Graph Latency Optimization
- Parallelized explicit `r` refresh (`RefreshConversations`) across up to 20 channel deltas (`buffer_unordered(5)`) overlapped with peer presence polling, emitting `TeamsUpdated` immediately.
- Parallelized background Tier 3 rotating channel polls and overlapped them with presence polling in `channel_tick`.
- Executed multi-chunk `$batch` requests concurrently (`buffered(4)`) and overlapped per-team channel pagination/fallback calls (`buffered(6)`).
- Memoized unsupported `/users?$filter` tenants per `GraphClient` instance and stopped redundant fallback retries on 401/403.
- Overlapped `require_my_user_id` + `get_json` in `edit_channel_post_subject`, `get_me` + `get_my_presence` in `doctor --probe`, and switched `build_quote_reply` cache misses to a single targeted `get_message` call.

### TUI Startup & Navigation Responsiveness
- Removed the duplicate blocking startup `bootstrap_conversations` call in `cmd_tui` and streamed live peer presences asynchronously after emitting `BootstrapDone`.
- Rendered cached conversations immediately on frame 1 (`select_initial_cached_conversation`), replaced cold `limit=60` 2-RTT room fetches with single-RTT `limit=50`, and added bounded rate-limited interactive neighbor prefetching.

### Test Hardening
- Guarded unit-test config and draft persistence from mutating the host user config directory (`#[cfg(test)]`).
