## What's Changed

### Symlinked `$HOME`, Keyring & npm Postinstall Hardening
- Fixed `scripts/postinstall.mjs` main-module guard using `fs.realpathSync` so native binary linking runs when `$HOME` or the npm prefix is a symlink.
- Canonicalized existing ancestors in `normalize_profile_dir` so symlinked `$HOME` defaults and canonical `TEAMS_CONFIG_DIR` paths resolve to the exact same OS keyring account.
- Canonicalized daemon Unix socket path hashes and isolated `XDG_RUNTIME_DIR` fallback sockets per profile.
- Preserved dotfile symlinks in `write_atomic` while refusing symlink writes on `0600` secret files, expanded `~/` on `TEAMS_CONFIG_DIR`/`TEAMS_DATA_DIR`/`$EDITOR`, and resolved symlinked binaries in `updater.rs`.

### Compact Attachment Stubs
- Included non-empty `content_type` on compact message attachment stubs (e.g. `application/vnd.microsoft.card.adaptive`) so unnamed Adaptive Cards are distinguishable without calling `compact: false`.
