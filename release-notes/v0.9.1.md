## Changes

- **Uploads**: small-file uploads now use `conflictBehavior=rename`, like large uploads, so sending a second file with the same name no longer replaces the first.
- **Write retries**: POST requests are retried only on 429/503. A 502/504 is reported instead of replayed, so a message is no longer posted twice.
- **`teams serve`**: a loopback server without `--token` generates a random bearer token per session and prints it once to stderr (`--allow-keyless` opts out). Requests must name the loopback host, and an `Origin` is accepted only from the API itself or an exact `--cors-origin` value.
- **Sync and cache**: a throttled or failed `$batch` chat stays dirty and is fetched again. A deleted channel (404) leaves the background rotation without stalling the batch. Teams and channels that Graph no longer lists are removed from the cache. Chat list cursors re-read the page they stopped in. Local pins survive a refresh.
- **History**: the TUI no longer reports "all older messages loaded" while older cached rows remain. A plain `teams read` no longer resets a deeper history cursor. Jumping to a search hit loads the history down to it. The thread drawer leaves the loading state when a refresh fails.
- **Profiles and daemon**: each `TEAMS_CONFIG_DIR` profile has its own keyring entry. `logout` stops the daemon, and `login` replaces a daemon signed in as another account. A one-off `TEAMS_*` environment override is no longer written into `config.toml`.
- **Corporate proxies**: the OS certificate store is now trusted alongside the bundled roots. Extra PEM roots can be added with `TEAMS_EXTRA_CA_PEM`, `SSL_CERT_FILE` or `NODE_EXTRA_CA_CERTS`. An untrusted-certificate failure reports `tls_untrusted_certificate` with a recovery hint, and `teams doctor` lists the extra CA sources. See `docs/ENTERPRISE.md`.
- **Hardening**: Graph credentials are sent only to the configured Graph origin, so a foreign `@odata.nextLink` fails. Chat creation works for addresses with a quote and for guest UPNs. The TUI opens only `http`, `https` and `mailto` links.
- **MCP**: the descriptions of request-heavy tools state their Graph request cost.

## Compatibility

- `teams serve` (breaking): a tokenless request with a non-loopback `Host` or a foreign `Origin` gets 403. Clients that reach the port through a reverse proxy or a custom hostname must use `--token`. Non-loopback binds always require `--token`, and `TEAMS_ALLOW_INSECURE_SERVE` no longer overrides this. Without a token, an `out_dir` outside the download directory gets 400 (`TEAMS_SERVE_ALLOW_ANY_OUT_DIR=1` restores the old behaviour). Attachment download and message delete with a body need `Content-Type: application/json` (415 otherwise). Wildcard CORS is gone: pass `--cors-origin` for each browser origin.
- `error.code`: `permission_denied` is now decided by the HTTP status, so some errors previously reported as `permission_denied` now report `not_found` or `error`.
- `export --include-threads` exits non-zero when reply fetches fail. The partial export is still written, and the failed threads are listed in `incomplete_threads` (JSON) and on stderr.
- A custom-directory profile that stored its token in the shared keyring slot reads its `credentials.json` copy on first run, so no new login is expected. The default profile is unchanged.
- Environment overrides already saved into `config.toml` by earlier versions are not removed. Edit the file to remove them.
