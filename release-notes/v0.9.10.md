## What's Changed

### Performance Optimization Suite (SQLite/FTS5, TUI Gen-Cache, HTML Parser & Pixel Pipeline)
- **SQLite/FTS5 & `$batch` Coalescing**: Migrated `messages_fts` to `rowid`-indexed deletes (`O(N²) → O(log N)`), coalesced `$batch` chat upserts into a single `spawn_blocking` SQLite transaction, and converted remaining queries to `prepare_cached`.
- **O(1) TUI Generation Caching & HTML Parser**: Replaced per-frame Dual SipHash + `<img>` re-parsing with monotonic `u64` generation counters, upgraded `HtmlParseCache` to an O(1) slab LRU with single-pass HTML entity decoding, promoted `Selector::parse` to `LazyLock`, deferred `viewport_pixel_payload` in `tui.rs`, and sliced visible viewport rows in preview overlays.
- **Pixel Engine**: Upgraded Sixel quantization to flat 32K histogram + 5-5-5 LUT + 2-row `i16` dithering + fast ASCII RLE, switched PNG encoding to `Fast`/`NoFilter` (`fdeflate`), eliminated per-span `format!` in CLI output, and enabled `opt-level = 3` for codec/pixel crates.
