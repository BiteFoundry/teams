## Changes

Sending to a chat or channel by name now reports ambiguous matches. Replies check the requested message, and message edits preserve mention data. Find people with `teams users <QUERY>` or MCP `search_users`.

## Compatibility

- `send`, `reply`, and `send-file` now return a compact acknowledgement with `--json`. Use `message.msg_id` for the sent message ID, or add `--full` for the complete message and conversation. The matching MCP tools `send_message`, `reply_message`, and `send_file` accept `"compact": false` for the full response.
- When `whoami --json` finds an expired token, read `error.code` for `token_expired` and `error.details` for the account and expiry information previously at the top level.
