# v0.6.0 — Pure Microsoft Teams Separation, Deep `@odata.nextLink` History Pagination & Token Scope Diagnostics

Version `0.6.0` streamlines `@bitefoundry/teams` into a **100% pure, dedicated Microsoft Teams client** (removing Outlook & OneNote bloat, permissions, and secondary shims) while solving deep conversation history & older chat list loading end-to-end across TUI, CLI, HTTP API, and MCP.

## Deep Conversation History & Older Chats Pagination (`@odata.nextLink`)

- **Full Microsoft Graph Cursor Pagination (`list_messages_page` & `fetch_older_messages`)**: Walks `@odata.nextLink` (`$skiptoken`) pages across 1:1 chats, group/meeting chats, team channels (`?$expand=replies`), and multi-page channel threads — skipping system-event-only pages automatically and falling back cleanly to page 1 if a saved `$skiptoken` cursor expires (`400`/`404`/`410`).
- **Seamless TUI Infinite Scroll-Up & Viewport Anchoring**: Scrolling up (`↑`, `PgUp`, mouse wheel up) at the top of any chat or channel automatically fetches older messages from Graph into SQLite, prepends them while anchoring `chat_scroll` so the current reading line never jumps, displays an interactive top history status banner, and supports `o` (50 messages) / `H` (150-message deep backfill).
- **Older Conversations List Pagination**: Orders `/me/chats` by `lastMessagePreview/createdDateTime desc` (with automatic unordered fallback on unsupported tenants) and pages beyond the initial 50 conversations in both TUI (`Chats` tab scroll-down) and CLI (`teams chats --limit 200`).
- **Deterministic SQLite Tie-Breaking (`list_older_root_messages`)**: Uses `(created_at < ?2 OR (created_at = ?2 AND msg_id < ?3))` with a composite index so messages sharing identical timestamps at page boundaries are never skipped.
- **CLI, HTTP API & MCP Deep History Controls**:
  - `teams read <target> --before <ISO_OR_YYYY-MM-DD_OR_MSG_ID> --limit <N>`
  - `teams sync --chats <N> --depth <N> [--target <query>]`
  - `GET /conversations/{key}/messages?before=...&limit=...&fetch_older=true`
  - MCP `get_messages` with `before` and `limit`

## JWT Scope Diagnostics & Pure Teams OAuth Scopes

- **Automatic JWT `scp` / `roles` Diagnostics**: Detects restricted external tokens (such as `Chat.ReadBasic`-only tokens that block message bodies/history, or missing `Chat.Read` / `ChannelMessage.Read.All`) and surfaces clear Korean explanations in TUI startup toasts/banners, `teams whoami`, `teams doctor`, and `403 Forbidden` responses without falsely locking `oldest_reached`.
- **Pure Microsoft Teams Scope Set**: Strips `Mail.*`, `Calendars.*`, `Contacts.*`, `Tasks.*`, and `Notes.*` from default OAuth login scopes — requesting only the 10 Microsoft Teams delegated scopes (`Chat.ReadWrite`, `ChannelMessage.Read.All`, `ChannelMessage.Send`, `Team.ReadBasic.All`, `Channel.ReadBasic.All`, `Files.ReadWrite.All`, `Presence.ReadWrite`, `User.Read`, `User.ReadBasic.All`, `offline_access`).

## Pure Microsoft Teams Architecture

- **Separated Outlook & OneNote**: Removes all Outlook and OneNote modules, TUI tabs/overlays, CLI subcommands, HTTP routes, MCP tools, OAuth scopes, and `outlook`/`onenote` binary shims from `@bitefoundry/teams`, automatically dropping legacy Outlook/OneNote tables from existing `cache.db` files on upgrade (`SCHEMA_USER_VERSION = 50`).
