CLI and MCP conversation reads now return compact JSON by default. Responses identify omitted fields and provide a full-read hint. For expanded detail, use `teams read <chat> --json --full` or set `compact: false` in MCP.

Thread replies distinguish the loaded portion from the total. Member lists can be paged from cache and distinguish an empty team from a team whose membership has never been fetched.

Joined-team refreshes preserve cached channels when an individual channel request fails. Quoted messages retain attribution and preview text.
