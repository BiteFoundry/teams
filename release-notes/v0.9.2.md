## Changes

This release tightens the MCP tool surface and upgrades tool schema metadata for higher agent selection accuracy.

### MCP

- **Focused 16-tool surface**: removed `react_message`, `mark_read`, and `set_presence` from `teams mcp` to keep agent prompts lean and prevent accidental unread-state or presence changes. Reactions, read receipts, and presence updates remain available in the CLI, TUI, and local HTTP API.
- **Full MCP annotations and schema coverage**: added standard MCP `annotations` (`title`, `readOnlyHint`, `destructiveHint`, `idempotentHint`, `openWorldHint`), explicit usage guidance between sibling tools, permission/cost disclosures, and 100% parameter descriptions across all 16 MCP tools.
