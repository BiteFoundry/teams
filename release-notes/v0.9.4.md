## What's Changed

### Terminal Image Preview Quality & Protocol Detection
- Replaced hardcoded low-resolution downsampling and stretched aspect-ratio math with terminal cell-geometry sizing and accurate protocol detection across Kitty, iTerm2, Sixel, and half-block renderers.

### Native HTML/SVG/Canvas & Embedded Graphics Rendering
- Eliminated raw HTML/SVG/script source leaks in the HTML preview overlay and message parser by upgrading to pure-Rust `bitefoundry-html` (`resvg 0.50` + `tiny-skia` + `base64`) for inline `<svg>`, `<canvas>`, and `data:image/*` rendering, with an explicit `[o: Browser]` banner for external `<script src>` content.

### Unified Markdown Rendering & `.md` Attachment Preview
- Standardized Markdown parsing on `pulldown-cmark 0.13` via `bitefoundry-html::markdown` and enabled direct in-TUI `.md` attachment and file previews.

### Width-Aware Text Wrapping & Layout Parity
- Switched chat, thread, adaptive card, table, code block, and single-line input overlays (`search`, `path_input`, `new_chat`) to display-width-aware styled wrapping (`wrap_styled_spans` / `windowed_single_line_input`), preserving plain-text newlines without horizontal clipping.

### TUI Sync Guards, Overlay Dispatch & Mouse UX
- Hardened background sync guards, modal overlay dispatch/click activation, and pane scroll interactions.
